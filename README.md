# Outils fondamentaux — Python

Travaux pratiques du module "Outils fondamentaux" — IUT Nord Franche-Comté.

## Contenu du dépôt

```
tp/
    tp1.ipynb   — Calcul numérique
    tp2.ipynb   — Arithmétique et nombres premiers
    tp3.ipynb   — Polynômes et fonctions
    tp4.ipynb   — Matrices et systèmes linéaires
```

## TP

Chaque notebook contient les exercices du TP et les réponses dans les cellules de code. Pour exécuter : ouvrir dans JupyterLite puis `Maj+Entrée` dans les cellules.

## Projet

Le projet compare la méthode de Newton et la dichotomie pour trouver des racines de fonctions. Il implémente un solveur qui détecte quand Newton diverge ou cycle et bascule sur la dichotomie. Voir `projet/README_projet.md` pour les détails.
